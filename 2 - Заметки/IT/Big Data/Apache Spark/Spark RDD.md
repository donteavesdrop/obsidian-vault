RDD – Resilent Distributed DataSet
❖ Устойчивый распределенный набор данных – неизменяемая 
коллекция объектов, распределенная по нескольким машинам 
кластера. 
❖ В типичной программе Spark один или более RDD загружаются 
в качестве входных данных.
❖ Через серию преобразований они превращаются в набор целевых 
RDD, для которых выполняется действие (например, вычисление 
результатов или запись их в постоянное хранилище). 
❖ Spark может автоматически восстанавливать потерянные данные 
путем пересчета их из RDD, из которых он был вычислен.
❖ Загрузка RDD или выполнение преобразования не запускает 
обработку данных, а просто ведет к созданию плана для 
выполнения вычисления.
❖ Вычисление запускается только тогда, когда на RDD выполняется 
действие, возвращающее результат пользователю.

Преобразования и действия на RDD. 
Ленивые вычисления
![[Pasted image 20260408122911.png]]
❖ Преобразование генерирует новый 
RDD из существующего.
❖ Действие запускает вычисление на 
RDD и что-то делает с результатами -
либо возвращает их пользователю, 
либо сохраняет их во внешнем 
хранилище.
❖ Действия имеют мгновенный эффект.
❖ Преобразования ленивы в том смысле, 
что не выполняют никакой работы, 
пока не будет вызвано действие с 
преобразованным RDD.

**Часто используемые преобразования**

❖ .map(func) возвращает новый RDD, сформированный путем 
применения к каждому элементу источника функции func.
❖ .filter(func) возвращает новый RDD, сформированный путем выбора тех 
элементов источника, для которых func возвращает true.
❖ .sample(withReplacement, fraction, seed) выбирает часть данных из RDD 
с повторениями или без, используя заданное начальное значение 
генератора случайных чисел.
❖ При вызове для RDD из пар типа (K, V)
❖ .groupByKey() возвращает RDD из пар типа (K, Iterable V), проводя группировку по 
ключу.
❖ .reduceByKey(func) возвращает RDD из пар типа (K, V), где значения для каждого 
ключа агрегированы с использованием заданной функции func, которая должна иметь 
тип (V, V) ⇒ V.
❖ .aggregateByKey(zeroValue, seqOp, combOp) возвращает RDD из пар типа (K, U), где 
значения для каждого ключа агрегированы с использованием заданных функций 
комбинирования и нейтрального «нулевого» значения. Позволяет использовать тип 
агрегированного значения, отличный от типа входного значения.
❖ .sortByKey([ascending]) возвращает RDD из пар типа (K, V), отсортированных по 
ключам в порядке возрастания или убывания, как указано в аргументе ascending.

Часто используемые преобразования (операции с множествами и отношениями)

❖ .union(otherDataset) возвращает новый RDD, содержащий объединение 
элементов исходного RDD и переданного в качестве аргумента.
❖ .intersection(otherDataset) возвращает новый RDD, содержащий пересечение 
элементов исходного RDD и переданного в качестве аргумента.
❖ .distinct([numTasks]) возвращает новый RDD, содержащий только уникальные 
элементы из исходного RDD.
❖ При вызове для RDD из пар типа (K, V) и (K, W)
❖ .join(otherDataset, [numTasks]) возвращает RDD из пар типа (K, (V, W)) со всеми парами элементов 
для каждого ключа. Внешние соединения поддерживаются через leftOuterJoin, rightOuterJoin и 
fullOuterJoin.
❖ .cogroup(otherDataset, [numTasks]) возвращает RDD из пар типа (K, (Iterable V, Iterable W)).
❖ .cartesian(otherDataset) при вызове для RDD из значений типов T и U 
возвращает RDD из пар типа (T, U) (все пары элементов).

Часто используемые действия
❖ .saveAsTextFile(path) — сохраняет данные в текстовый файл (в 
HDFS, на локальную машину или в любую другую 
поддерживаемую файловую систему)
❖ .collect() — возвращает элементы RDD в виде списка. Как 
правило, это применяется в случаях, когда данных уже мало 
(применены различные фильтры и преобразования) — и 
необходима визуализация, либо дополнительный анализ 
данных, например средствами пакета Pandas.
❖ .take(n) — возвращает в виде списка первые n элементов RDD.
❖ .count() — возвращает количество элементов в RDD.
❖ .reduce(f) — проводит редукцию RDD с использованием 
коммутативного ассоциативного бинарного оператора.


SparkContext: точка входа в API Spark
❖ Представляет соединение с кластером Spark.
❖ В интерактивной оболочке pyspark всегда 
предопределен и доступен под 
идентификатором sc.
❖ В отдельном скрипте требуется 
инициализация:
from pyspark.context import SparkContext
sc = SparkContext('local', 'test')

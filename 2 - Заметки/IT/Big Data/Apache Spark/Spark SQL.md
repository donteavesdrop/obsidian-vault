Spark SQL
❖ Spark SQL - это модуль Spark для обработки 
структурированных данных.
❖ В отличие от базового Spark RDD API, интерфейсы, 
предоставляемые Spark SQL, снабжают Spark 
дополнительной информацией о структуре как данных, так и 
выполняемых вычислений.
❖ Внутри Spark SQL использует эту дополнительную 
информацию для выполнения дополнительных 
оптимизаций.

Dataset и DataFrame
❖ Dataset - это распределенный набор данных. 
❖ Dataset - это новый интерфейс, добавленный в Spark 1.6, который 
предоставляет преимущества RDD (строгая типизация, возможность 
использования мощных лямбда-функций) с преимуществами 
оптимизированного механизма выполнения Spark SQL.
❖ Dataset можно создать из объектов JVM, а затем управлять им с помощью 
функциональных преобразований (map, filter, и др.).
❖ Dataset API доступен на Scala и Java. Python не поддерживает Dataset API.
❖ DataFrame - это Dataset, организованный в именованные столбцы. 
❖ Эквивалент таблице в реляционной базе данных, но с более обширной 
внутренней оптимизацией. 
❖ DataFrame могут быть созданы из широкого спектра источников, таких как 
структурированные файлы данных, внешние базы данных или 
существующие RDD. 
❖ API DataFrame доступен в Scala, Java, Python и R. 
❖ В Scala и Java DataFrame представлен набором строк.

Часто используемые операции 
DataFrame: реляционная алгебра
❖ select(*cols) - проецирует набор выражений и возвращает новый DataFrame.
❖ filter(condition) - фильтрует строки применяя переданное условие.
❖ orderBy(*cols, **kwargs) - возвращает новый DataFrame, отсортированный по 
указанным столбцам.
❖ show(n, truncate, vertical) - выводит первые n строк на терминал.
❖ union(other) - возвращает новый DataFrame, содержащий объединение строк 
данного DataFrame и переданного.
❖ intersect(other) - возвращает новый DataFrame, содержащие только строки, 
встречающиеся одновременно в данном DataFrame и переданном.
❖ join(other, on, how) - выполняет соединение с другим DataFrame по указанному 
условию.
❖ crossJoin(other) - возвращает декартово произведение с другим DataFrame.
❖ limit(num) - ограничивает количество строк заданным значением.


SparkSession: точка входа в API Spark 
DataFrame, DataSet
❖ В интерактивной оболочке pyspark всегда 
предопределен и доступен под идентификатором 
spark.
❖ В отдельном скрипте требуется инициализация:
from pyspark.sql import SparkSession
spark = SparkSession.builder \
.master("local") \
.appName("test") \
.getOrCreate()

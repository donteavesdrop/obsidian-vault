## ArenaData (Аренадата)

**ArenaData** — российское программное обеспечение с характеристиками:

- полная локализация
- техническая поддержка на русском языке
- отсутствие проприетарных компонентов
- весь дистрибутив собран из открытых проектов Apache Software Foundation

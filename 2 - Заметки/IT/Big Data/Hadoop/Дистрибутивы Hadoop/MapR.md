## MapR

**Дистрибутив MapR** использует собственные компоненты вместо стандартных открытых решений:

| Компонент MapR | Заменяемый компонент |
|----------------|---------------------|
| **MapR-FS** | HDFS |
| **MapR-DB** | база данных |
| **MapR Event Store** | Apache Kafka |

### Коммерческие версии

**Enterprise Edition M5** и **Enterprise Database Edition M7** обеспечивают:

- высокую доступность и защиту данных
- мультиузловый NFS
- данные структурированных таблиц изначально на уровне хранилища

#L3

----
**IGMP (Internet Group Management Protocol)** — это протокол управления групповой (multicast) передачей данных в IPv4-сетях. Он используется хостами и соседними маршрутизаторами для сообщения о членстве в multicast-группах, то есть для указания, какие устройства хотят получать трафик, предназначенный для определённой группы получателей[](https://ru.wikipedia.org/wiki/IGMP)[](https://www.smart-soft.ru/blog/mezhsetevoj_protokol_upravlenija_gruppami_igmp/).

---

### Особенности

IGMP решает ключевую задачу: без него маршрутизатор был бы вынужден рассылать multicast-трафик всем без исключения устройствам в сети, что привело бы к огромной нагрузке. Протокол позволяет маршрутизатору узнавать, кому именно нужны эти данные, и отправлять их только заинтересованным узлам[](https://ru.wikipedia.org/wiki/IGMP).

IGMP является неотъемлемой частью стека TCP/IP и напрямую инкапсулируется в IP-пакеты (с номером протокола 2). В отличие от протоколов обмена маршрутной информацией (OSPF, RIP), IGMP не занимается построением таблиц маршрутизации. Его задача — управление подпиской на локальном сегменте сети[](https://ru.wikipedia.org/wiki/IGMP)[](https://www.smart-soft.ru/blog/mezhsetevoj_protokol_upravlenija_gruppami_igmp/).

Существует три версии протокола: IGMPv1 (RFC 1112), IGMPv2 (RFC 2236) и IGMPv3 (RFC 3376). Каждая последующая версия добавляет новые возможности, например, IGMPv2 ввёл сообщение Leave Group, позволяющее хосту корректно выйти из группы, а IGMPv3 — поддержку Source-Specific Multicast (SSM), где хост может указать не только группу, но и конкретного отправителя (источник), от которого он хочет получать трафик.

Основные типы IGMP-сообщений:

- **Membership Query (Запрос)**: Рассылается маршрутизатором для опроса членов групп. Бывают общие (General Query — ко всем группам), специальные с указанием группы (Group-Specific Query) и с указанием группы и источника (Group-and-Source-Specific Query)[](https://ru.wikipedia.org/wiki/IGMP).
    
- **Membership Report (Отчёт о членстве)**: Отправляется хостом в ответ на запрос маршрутизатора или добровольно (для анонсирования присоединения к группе)[](https://ru.wikipedia.org/wiki/IGMP).
    
- **Leave Group (Выход из группы)**: Позволяет хосту явно сообщить маршрутизатору о своём выходе из multicast-группы.

### Как и где применяется

IGMP критически важен для всех приложений, использующих multicast-рассылку в IPv4-сетях. Он позволяет эффективно доставлять данные от одного отправителя множеству получателей, экономя сетевые ресурсы.

Основные области применения включают:

- **IPTV и потоковое видео**: Провайдеры используют IGMP, чтобы доставлять телевизионные каналы только тем абонентам, которые их смотрят.
    
- **Видеоконференции**: Для одновременной передачи видео и аудио между несколькими участниками.
    
- **Онлайн-игры и биржевые котировки**: Для оперативной доставки данных в реальном времени.
    
- **Промышленные сети и управление**: Для синхронизации устройств и оповещений в системах SCADA[](https://ru.wikipedia.org/wiki/IGMP).

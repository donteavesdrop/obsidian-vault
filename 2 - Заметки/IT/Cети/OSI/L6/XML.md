**XML (eXtensible Markup Language)** — это не протокол, а текстовый язык разметки и формат данных, предназначенный для хранения, передачи и восстановления структурированной информации между различными системами. Как и HTML, XML является производным от более старого стандарта SGML, но в отличие от HTML, который описывает внешний вид страницы, XML описывает _содержание_ и _структуру_ данных. Благодаря своей строгости и гибкости, XML стал основой для множества протоколов и форматов обмена данными, включая SOAP, RSS, XHTML, а также файлов конфигураций.

---

### Принцип работы

XML — это метаязык, то есть он не имеет предопределённого набора тегов. Вместо этого он предоставляет синтаксические правила, позволяющие разработчикам создавать свои собственные теги, атрибуты и структуры, наиболее подходящие для их данных. XML-документ представляет собой иерархическое дерево элементов, которое одновременно является и "человекочитаемым", и "машиночитаемым". Любое XML-приложение выполняет две ключевые операции:

1. **Сериализация** — преобразование внутренних структур данных приложения (объектов, записей) в XML-документ (текстовый файл).
    
2. **Десериализация (парсинг)** — разбор XML-документа для восстановления исходной структуры данных в принимающей системе.
    

Для того чтобы две разные системы могли однозначно понимать друг друга, они должны договориться об используемом словаре тегов и структуре документа. Эта договорённость может быть зафиксирована в виде DTD (Document Type Definition) или XML Schema (XSD), которые служат "схемой данных" для конкретного XML-приложения.

### Особенности

1. **Разделение содержимого и представления.** XML описывает данные, а не то, как их отображать. Для форматирования XML-данных обычно используются CSS или XSLT (Extensible Stylesheet Language Transformations).
    
2. **Строгий синтаксис.** В отличие от HTML, XML очень требователен к соблюдению правил:
    
    - Каждый открывающий тег должен иметь соответствующий закрывающий тег.
        
    - Теги чувствительны к регистру (`<Name>` и `<name>` — разные теги).
        
    - Значения атрибутов должны быть заключены в кавычки.
        
    - Должен быть один корневой элемент.
        
3. **Расширяемость.** Пользователь может создавать любые теги, не ограниченные фиксированным набором, что делает XML идеальным для представления любых предметных областей.
    
4. **Иерархическая (древовидная) структура.** Данные всегда организованы в виде дерева с одним корневым элементом и вложенными дочерними элементами, что наглядно отражает связи "родитель-потомок".
    
5. **Встроенная поддержка Unicode.** XML изначально поддерживает символы любых языков мира, что позволяет создавать документы на русском, китайском, арабском и других языках без использования специальных кодировок.
    
6. **Пространства имён (Namespaces).** Позволяют смешивать в одном документе теги из разных XML-словарей, разрешая конфликты имён (например, использовать `<table>` из HTML и `<table>` из описания мебели).
    
7. **"Самодокументируемость" и избыточность.** XML-документы являются самодостаточными: имена тегов и атрибутов объясняют смысл данных. Однако это достигается ценой большого объёма файла, что является основным недостатком по сравнению с более компактными форматами (JSON, Protocol Buffers).

### Как и где применяется

1. **Веб-сервисы (SOAP, XML-RPC).** Многие классические веб-сервисы для обмена сообщениями используют протокол SOAP, который представляет собой строго структурированный XML-конверт.
    
2. **Файлы конфигураций.** XML широко используется для хранения настроек в Java-приложениях (файлы web.xml, pom.xml для Maven), в средах Microsoft .NET (App.config), в различных фреймворках (Spring, Hibernate) и в IDE (конфигурации проектов).
    
3. **Офисные форматы.** Современные форматы офисных документов, такие как Microsoft Office Open XML (DOCX, XLSX, PPTX) и OpenDocument Format (ODT, ODS), представляют собой ZIP-архивы, содержащие набор XML-файлов.
    
4. **Синдикация контента (RSS, Atom).** Ленты новостей и подкастов в форматах RSS и Atom — это XML-документы, которые позволяют подписываться на обновления сайтов.
    
5. **Базы данных и обмен данными.** XML используется для импорта/экспорта данных между различными СУБД, в системах электронного документооборота (счета-фактуры, юридически значимые документы), а также в форматах обмена научными данными (MathML для формул, CML для химии, GML для географии).
    
6. **Промышленные стандарты.** XML является основой для многих отраслевых стандартов, включая:
    
    - **Транспорт**: FIX (финансовые транзакции), ebXML (бизнес-транзакции).
        
    - **Медицина**: HL7 (обмен медицинской информацией).
        
    - **Автоматизация**: AutomationML (обмен данными в промышленности).

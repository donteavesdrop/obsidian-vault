**NetBIOS (Network Basic Input/Output System)** — это не сетевой протокол в чистом виде, а программный интерфейс (API), разработанный для организации взаимодействия между приложениями на разных компьютерах в локальной сети (LAN). Созданный в начале 1980-х годов, он обеспечивает службы сеансового уровня модели OSI и предоставляет прикладным программам универсальные функции для поиска других устройств, установления соединений и обмена данными, скрывая от них аппаратные детали сети[](https://www.techtarget.com/searchnetworking/definition/NetBIOS).

---

### Принцип работы

Работа NetBIOS строится на трёх основных службах, каждая из которых использует определённые сетевые порты:

- **Служба имён (Name Service)**: Для идентификации и обнаружения устройств и сервисов. Каждый компьютер в сети получает уникальное 16-символьное имя. Эта служба работает через широковещательные запросы и сервер WINS, используя порты 137 (UDP/TCP)[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios).
    
- **Служба дейтаграмм (Datagram Service)**: Для быстрой передачи небольших пакетов данных без установки постоянного соединения. Эта служба не гарантирует доставку и использует порт 138 (UDP)[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios).
    
- **Служба сессий (Session Service)**: Для надёжной, полноценной передачи больших объёмов данных. Перед началом обмена между компьютерами устанавливается логическое соединение, которое гарантирует доставку и порядок следования пакетов. Эта служба использует порт 139 (TCP)[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios).

### Особенности

1. **Это API, а не протокол**: Ключевая особенность NetBIOS. Он лишь предоставляет стандартизированный набор команд для приложений, а фактическую передачу данных по сети выполняют другие протоколы: первоначальный **NetBEUI** (немаршрутизируемый, для малых сетей), **IPX/SPX** или современный **TCP/IP** (в виде NBT)[](https://en.wikipedia.org/?curid=177746)[](https://ru.wikipedia.org/api/rest_v1/page/mobile-html/NetBIOS).
    
2. **Маршрутизация NetBIOS over TCP/IP (NBT)**: Исходный NetBIOS не поддерживал маршрутизацию, работая только в пределах одного сетевого сегмента. Благодаря NBT (RFC 1001/1002), службы NetBIOS были адаптированы для работы поверх TCP/IP, что позволило им функционировать в больших составных сетях[](https://www.techtarget.com/searchnetworking/definition/NetBIOS)[](https://en.wikipedia.org/wiki/NetBIOS_over_TCP/IP).
    
3. **WINS для централизованного управления**: Для маршрутизируемых сетей был создан WINS — централизованный сервер, который хранил базу соответствия имён NetBIOS и IP-адресов, ускоряя разрешение имён[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios)[](http://book.itep.ru/4/41/4/42/nbio_423.htm).
    
4. **Устаревший статус и проблемы безопасности**: NetBIOS был разработан в эпоху доверительных локальных сетей и не имеет встроенных механизмов безопасности. Он уязвим для атак, раскрывает информацию о структуре сети и является причиной многих проблем с совместимостью современных протоколов. В большинстве современных корпоративных сред его отключают[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios)[](https://en.wikipedia.org/wiki/NetBIOS_over_TCP/IP).

### Как и где применяется

1. **Устаревшие и корпоративные системы**: NetBIOS по-прежнему используется в старых версиях Windows и для обратной совместимости в Windows 10/11. Часто встречается в устаревшей, но критически важной инфраструктуре (склады, производства), где модернизация дорога или рискованна[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios).
    
2. **Совместное использование ресурсов**: Функции NetBIOS исторически являются основой для обмена файлами и принтерами по протоколу SMB/CIFS. Именно через службу сессий NetBIOS (порт 139) устанавливались классические сессии для доступа к сетевым дискам и принтерам[](https://wirexsystems.com/resource/protocols/netbios/).
    
3. **Инструменты пентеста**: Для специалистов по кибербезопасности знание NetBIOS важно, так как он остаётся вектором для атак (например, перехват сессий) и часто используется для разведки и сбора информации о сети (net view, nbtstat)[](https://jumpcloud.com/it-index/understanding-network-basic-input-output-system-netbios)

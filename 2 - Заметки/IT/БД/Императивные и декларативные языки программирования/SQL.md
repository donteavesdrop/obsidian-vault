## Что такое язык SQL

**SQL** (Structured Query Language) — это **декларативный язык**, который является стандартным средством работы с данными во всех реляционных СУБД.

### Принцип работы

Операторы SQL лишь указывают СУБД, **какой результат** должен быть получен, но не описывают процедуру получения этого результата.

## Процесс SQL

Когда выполняется команда SQL для любой СУБД, система определяет **лучший способ выполнить запрос**, а механизм SQL выясняет, как интерпретировать задачу.

### Компоненты процесса SQL

В этот процесс включены различные компоненты:

- Диспетчер запросов
- Двигатели оптимизации
- Классический Query Engine
- SQL Query Engine
- и т.д.

## Типы операторов SQL

### DDL (Data Definition Language / Язык определения данных)

К этому типу относятся различные команды, которые создают базу данных, таблицы, индексы, хранимые процедуры и т.д. В общем — **определяют данные**.

### DML (Data Manipulation Language / Язык манипуляции данными)

К этому типу относят команды на выборку данных, их обновление, добавление, удаление — все те команды, с помощью которых происходит **управление данными**.

### DCL (Data Control Language / Язык управления доступом к данным)

К этому типу относят команды, которые управляют **правами доступа** к данным.

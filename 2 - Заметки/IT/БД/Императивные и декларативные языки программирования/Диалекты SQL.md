## Диалекты языка SQL

Выделяются несколько диалектов языка SQL:

| Диалект | СУБД / Сфера применения |
|---------|------------------------|
| **PL/SQL** | Oracle, PostgreSQL, MySQL |
| **T-SQL** (Transact-SQL) | SQL Server |
| **YQL** (YDB Query Language) | Универсальный декларативный язык запросов к YDB, работа с большими распределенными базами данных |
| **AQL** (Array Query Language) | Работа не с таблицами, а с массивами; позволяет анализировать не только конкретные точки, но и их окрестности |

## NULL-значения и их обработка

### Определение NULL

`NULL` представляет отсутствие значения или неизвестное значение в базе данных.

### Особенности

`NULL` не равно пустой строке или нулю. Операции с `NULL` дают специфические результаты.

### Обработка

Системы, управляющие базами данных, предоставляют специальные функции для работы с `NULL`.

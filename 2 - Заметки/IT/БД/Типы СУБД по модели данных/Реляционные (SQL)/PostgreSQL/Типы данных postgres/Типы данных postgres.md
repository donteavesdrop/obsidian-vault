## 💡 Ключевые особенности:

- **text** - основной тип для строк без ограничений длины
- **varchar(n)** - используют когда нужны гарантии по длине
- **jsonb** - предпочтительнее json для большинства случаев
- **serial** - не настоящий тип, а удобное соглашение для автоинкремента
- **array** - могут быть многомерными: `integer[][]`, `text[]`

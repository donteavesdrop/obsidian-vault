## PostgreSQL

**PostgreSQL** — одна из наиболее популярных систем управления базами данных.

### Ключевые особенности

- **Open Source** — полностью бесплатная и открытая СУБД
- **Не требует сложной настройки** — низкий порог входа
- **Развитый диалект PL/SQL** — мощный язык процедурного программирования
- **Совместимость** — 90% возможностей диалекта PL/SQL можно использовать в других СУБД

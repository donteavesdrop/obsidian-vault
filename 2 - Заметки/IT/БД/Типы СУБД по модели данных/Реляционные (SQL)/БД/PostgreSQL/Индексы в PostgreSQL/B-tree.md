### Пример создания B-Tree индекса

```sql
CREATE TABLE people (
    last_name TEXT NOT NULL,
    first_name TEXT NOT NULL,
    dob TIMESTAMP NOT NULL,
    gender INT NOT NULL
);

CREATE INDEX idx_people_name
ON people
USING btree (last_name, first_name, dob);
```

### Особенности B-Tree индекса

#### ✅ Можно

| Возможность | Описание |
|-------------|----------|
| **Поиск по полному значению** | точное совпадение по всем столбцам индекса |
| **Поиск по самому левому префиксу** | поиск только по первому(‑ым) столбцу(‑ам) |
| **Поиск по диапазону значений** | условия `>`, `<`, `BETWEEN` и т.д. |
| **Поиск по полному совпадению одной части и диапазону в другой** | комбинированные условия |
| **Запросы только по индексу** | все нужные поля есть в индексе (Index Only Scan) |

#### ❌ Нельзя

| Ограничение | Пояснение |
|-------------|-----------|
| **Поиск без использования левой части ключа** | нельзя искать по `first_name`, если индекс на `(last_name, first_name, dob)` — левая часть `last_name` пропущена |
| **Нельзя пропускать столбцы** | если индекс на `(a, b, c)`, то условия на `a` и `c` без `b` использовать левую часть не получится |

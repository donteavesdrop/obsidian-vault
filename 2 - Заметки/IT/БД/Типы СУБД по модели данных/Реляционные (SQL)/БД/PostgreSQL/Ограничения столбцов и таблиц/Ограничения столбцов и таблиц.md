## Ограничения столбцов и таблиц

**Ограничения** – это правила, применяемые к столбцам данных в таблице. Они используются для предотвращения ввода неверных данных в базу данных.

### Виды ограничений

- **Ограничения уровня столбца** – применяются только к одному столбцу
- **Ограничения уровня таблицы** – применяются ко всей таблице

---

## Значения по умолчанию (DEFAULT)

Столбцу можно назначить **значение по умолчанию**. Когда добавляется новая строка и каким-то её столбцам не присваиваются значения, эти столбцы принимают значения по умолчанию.

```sql
CREATE TABLE progress
...
mark numeric(1) DEFAULT 5,
...
```

---

## Ограничение CHECK

Это ограничение бывает двух видов:
- **Ограничение уровня атрибута** – является частью определения одного конкретного атрибута
- **Ограничение уровня таблицы** – записывается как самостоятельный элемент определения таблицы

```sql
CREATE TABLE progress
(...
  term numeric(1) CHECK (term = 1 OR term = 2),
  mark numeric(1) CHECK (mark >= 3 AND mark <= 5),
...
);
```

---

## Имя ограничения (CONSTRAINT)

Каждое ограничение имеет имя. Мы можем задать его сами с помощью ключевого слова `CONSTRAINT`. Если же мы этого не сделаем, СУБД сформирует имя автоматически.

```sql
CREATE TABLE progress
( ...
  mark numeric(1),
  CONSTRAINT valid_mark CHECK (mark >= 3 AND mark <= 5),
...
);
```

---

## Ограничение NOT NULL

Означает, что в столбце таблицы, на который наложено это ограничение, должны обязательно присутствовать какие-либо определенные значения. При разработке баз данных, исходя из логики конкретной предметной области, зачастую требуется использовать это ограничение.

```sql
CREATE TABLE COMPANY1(
  ID INT PRIMARY KEY NOT NULL,
  NAME TEXT NOT NULL,
  AGE INT NOT NULL,
  ADDRESS CHAR(50),
  SALARY REAL
);
```

---

## Ограничение уникальности UNIQUE

Такое ограничение, наложенное на конкретный столбец, означает, что все значения, содержащиеся в этом столбце в различных строках таблицы, должны быть **уникальными**.

```sql
CREATE TABLE students
( record_book numeric(5),
  name text NOT NULL,
  ...
  CONSTRAINT unique_record_book UNIQUE (record_book),
  ...
);
```

| Ключевое слово | Значение |
|----------------|----------|
| `CONSTRAINT` | Осмысленное имя ограничения |
| `UNIQUE` | Имя уникального столбца (столбцов) |

---

## Множественное ограничение уникальности

Можно создать ограничение уникальности, включающее **более одного столбца**.

```sql
CREATE TABLE students
( ...
  doc_ser numeric(4),
  doc_num numeric(6),
  ...
  CONSTRAINT unique_passport UNIQUE (doc_ser, doc_num),
...
);
```

## SQL: Синтаксис и основные операции

### Общие правила синтаксиса

- **Зарезервированные ключевые слова** (несколько десятков)
- **Регистр** (почти всегда) игнорируется
- **Константы:** `123`, `12.3`, `"Текстовые строки"`
- **Имена:** `FLIGHTS`, `Bookings`, `flights.departure_airport`, `"SELECT"`, `"Имя"`
- **Операторы, предложения, выражения**

### Пример вставки данных

```sql
INSERT INTO albums (title, release_date, recording_date)
VALUES ('Charcoal Lane', '1990-01-01 01:01:01.00000', '1990-01-01 01:01:01.00000'),
       ('The New Danger', '2008-01-01 01:01:01.00000', '1990-01-01 01:01:01.00000');
```

## Создание таблиц (CREATE TABLE)

### Синтаксис

```sql
CREATE TABLE "имя таблицы" (
    имя_поля тип_данных [ограничения целостности],
    имя_поля тип_данных [ограничения целостности],
    ...
    имя_поля тип_данных [ограничения целостности],
    [ограничение целостности],
    [первичный ключ],
    [внешний ключ]
);
```

### Пример создания таблицы `aircrafts`

```sql
CREATE TABLE aircrafts (
    aircraft_code char(3) NOT NULL,
    model text NOT NULL,
    range integer NOT NULL,
    CHECK (range > 0),
    PRIMARY KEY (aircraft_code)
);
```

### Описание атрибутов таблицы `aircrafts`

| Атрибут | Описание | Тип данных | Тип PostgreSQL | Ограничения |
|---------|----------|------------|----------------|-------------|
| `aircraft_code` | Код самолета (IATA) | Символьный | `char(3)` | `NOT NULL` |
| `model` | Модель самолета | Символьный | `text` | `NOT NULL` |
| `range` | Максимальная дальность полета (км) | Числовой | `integer` | `NOT NULL`, `range > 0` |

## Вставка строк в таблицу (INSERT)

### Синтаксис

```sql
INSERT INTO имя_таблицы [(имя_атрибута, имя_атрибута, ...)]
VALUES (значение_атрибута, значение_атрибута, ...);
```

> **Примечание:** атрибуты можно указывать не в том порядке, в котором они были заданы при создании таблицы.

### Пример вставки одной строки

```sql
INSERT INTO aircrafts (aircraft_code, model, range)
VALUES ('SU9', 'Sukhoi SuperJet-100', 3000);
```

### Вставка нескольких строк

```sql
INSERT INTO aircrafts (aircraft_code, model, range)
VALUES ('773', 'Boeing 777-300', 11100),
       ('763', 'Boeing 767-300', 7900),
       ('733', 'Boeing 737-300', 4200),
       ('319', 'Airbus A319-100', 6700),
       ('CN1', 'Cessna 208 Caravan', 1200),
       ('CR2', 'Bombardier CRJ-200', 2700);
```

**Результат:** `INSERT 0 8` (8 строк успешно вставлено)

## Выборка строк из таблицы (SELECT)

### Синтаксис

```sql
SELECT имя_атрибута, имя_атрибута, ... FROM имя_таблицы;
SELECT * FROM имя_таблицы;  -- выбрать все столбцы
```

> ⚠️ При выполнении простой выборки СУБД **не гарантирует** конкретный порядок вывода строк.

### Пример

```sql
SELECT * FROM aircrafts;
```

**Результат:**

| aircraft_code | model | range |
|---------------|-------|-------|
| SU9 | Sukhoi SuperJet-100 | 3000 |
| 773 | Boeing 777-300 | 11100 |
| 763 | Boeing 767-300 | 7900 |
| 733 | Boeing 737-300 | 4200 |
| 320 | Airbus A320-200 | 5700 |
| 321 | Airbus A321-200 | 5600 |
| 319 | Airbus A319-100 | 6700 |
| CN1 | Cessna 208 Caravan | 1200 |
| CR2 | Bombardier CRJ-200 | 2700 |

*(9 строк)*

## Фильтрация данных (WHERE)

### Пример: выборка самолетов с дальностью от 4000 до 6000 км

```sql
SELECT model, aircraft_code, range
FROM aircrafts
WHERE range >= 4000 AND range <= 6000;
```

**Результат:**

| model | aircraft_code | range |
|-------|---------------|-------|
| Boeing 737-300 | 733 | 4200 |
| Airbus A320-200 | 320 | 5700 |
| Airbus A321-200 | 321 | 5600 |

*(3 строки)*

## Обновление строк в таблице (UPDATE)

### Синтаксис

```sql
UPDATE имя_таблицы
SET имя_атрибута1 = значение_атрибута1,
    имя_атрибута2 = значение_атрибута2, ...
WHERE условие;
```

> ⚠️ **Внимание!** Если условие `WHERE` не задано, будут обновлены **ВСЕ** строки в таблице.

### Синтаксис

DELETE FROM имя_таблицы WHERE условие;

Условные выражения позволяют вывести то или иное значение в зависимости от условий

![[Pasted image 20260427164806.png]]

| Функция | Описание |
|---------|----------|
| `NULLIF` | возвращает NULL, если два аргумента равны |
| `GREATEST` | возвращает наибольшее значение из списка |
| `LEAST` | возвращает наименьшее значение из списка |

### Примеры

```sql
SELECT NULLIF(1, 1);  -- возвращает NULL

SELECT GREATEST(3, 15, 7);  -- возвращает 15

SELECT LEAST(1, -1, -2, 2);  -- возвращает -2

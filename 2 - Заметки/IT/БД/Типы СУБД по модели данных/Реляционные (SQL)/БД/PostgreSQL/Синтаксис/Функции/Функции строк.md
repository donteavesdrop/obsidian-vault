## Строковые функции PostgreSQL

| Функция                                                        | Описание                                                                                                                      | Пример                             | Результат  |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ---------- |
| `string \|\| string`                                           | конкатенация строк                                                                                                            | `'Post' \|\| 'greSQL'`             | PostgreSQL |
| `lower(string)`                                                | преобразование строки в нижний регистр                                                                                        | `lower('TOM')`                     | tom        |
| `position(substring in string)`                                | расположение указанной подстроки                                                                                              | `position('om' in 'Thomas')`       | 3          |
| `substring(string [from int] [for int])`                       | извлечение подстроки                                                                                                          | `substring('Thomas' from 2 for 3)` | hom        |
| `substring(string from pattern)`                               | извлечение подстроки, соответствующей регулярному выражению POSIX                                                             | `substring('Thomas' from '...$')`  | mas        |
| `trim([leading \| trailing \| both] [characters] from string)` | удаление самой длинной строки, содержащей только указанные символы (по умолчанию пробел), из начала/конца/обоих концов строки | `trim(both 'x' from 'xTomxx')`     | Tom        |
| `upper(string)`                                                | преобразование строки в верхний регистр                                                                                       | `upper('tom')`                     | TOM        |

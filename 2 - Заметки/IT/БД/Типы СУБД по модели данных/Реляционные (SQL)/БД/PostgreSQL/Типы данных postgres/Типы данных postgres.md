# Типы данных в PostgreSQL

## 🔢 Числовые типы

| Название | Кол-во байт | Описание | Диапазон |
|----------|-------------|----------|----------|
| `smallint` | 2 байт | целое малого диапазона | от -32,768 до +32,767 |
| `integer` | 4 байт | стандартное целое | от -2,147,483,648 до +2,147,483,647 |
| `bigint` | 8 байт | целое расширенного диапазона | от -9,223,372,036,854,775,808 до +9,223,372,036,854,775,807 |
| `decimal` / `numeric` | переменная | число с фиксированной точностью, заданной пользователем | до 131,072 знаков до запятой, до 16,383 после |
| `real` | 4 байт | число с плавающей точкой (неточное) | точность до 6 десятичных цифр |
| `double precision` | 8 байт | число с плавающей точкой (неточное) | точность до 15 десятичных цифр |
| `smallserial` | 2 байт | автоинкремент малого диапазона | от 1 до 32,767 |
| `serial` | 4 байт | автоинкремент | от 1 до 2,147,483,647 |
| `bigserial` | 8 байт | автоинкремент расширенного диапазона | от 1 до 9,223,372,036,854,775,807 |
| `money` | 8 байт | денежный тип (2 знака после запятой) | от -92,233,720,368,547,758.08 до +92,233,720,368,547,758.07 |

### 📌 Особенности числовых типов

#### Числа фиксированной точности (`numeric` / `decimal`)

- **Идентичны** по своим возможностям
- Параметры: `numeric(точность, масштаб)`
  - **Точность (precision)** — общее число цифр (до и после запятой)
  - **Масштаб (scale)** — число цифр после десятичной точки
- Пример: `numeric(6, 2)` — всего 6 цифр, из них 2 после запятой

#### Последовательные типы (`serial`, `bigserial`, `smallserial`)

> ⚠️ **Важно:** `serial` — не настоящий тип данных, а удобное соглашение (синтаксический сахар)

```sql
-- Эта команда:
CREATE TABLE tablename (colname SERIAL);

-- Эквивалентна:
CREATE SEQUENCE tablename_colname_seq;
CREATE TABLE tablename (
    colname INTEGER NOT NULL DEFAULT nextval('tablename_colname_seq')
);
ALTER SEQUENCE tablename_colname_seq OWNED BY tablename.colname;
```

## 📝 Символьные (строковые) типы

| Название | Описание |
|----------|----------|
| `character(n)` / `char(n)` | фиксированной длины, дополняется пробелами |
| `character varying(n)` / `varchar(n)` | переменной длины с ограничением до n символов |
| `text` | переменной длины без ограничений |

> **💡 Рекомендация:** `text` — основной тип для строк. `varchar(n)` используют, когда нужны гарантии по длине.

## 📅 Типы «дата / время»

| Название | Кол-во байт | Описание | Диапазон |
|----------|-------------|----------|----------|
| `date` | 4 байт | только дата | 4713 до н.э. – 294,276 н.э. |
| `time` | 8 байт | только время | 00:00:00 – 24:00:00 |
| `timestamp` | 8 байт | дата и время | 4713 до н.э. – 294,276 н.э. |
| `timestamptz` | 8 байт | дата, время и часовой пояс | 4713 до н.э. – 294,276 н.э. + часовой пояс |
| `interval` | 16 байт | разница между временными метками | ±178,000,000 лет |

### 📌 Особенности работы с датой и временем

- **Рекомендуемый формат ввода (ISO 8601):** `yyyy-mm-dd`
- `time` vs `time with time zone` — PostgreSQL рекомендует использовать `time with time zone`
- Для типа `timestamp` также поддерживается вариант с часовым поясом (`timestamptz`)

| `true` | `false` |

## 🔍 Перечисляемые типы (`ENUM`)

| Название | Лимит | Описание |
|----------|-------|----------|
| `enum` | до 65,535 значений | пользовательские типы с фиксированными значениями |

**Пример создания и использования:**

```sql
CREATE TYPE mood AS ENUM ('sad', 'ok', 'happy');

CREATE TABLE person (
    name text,
    current_mood mood
);

INSERT INTO person VALUES ('Vasya', 'happy');
SELECT * FROM person WHERE current_mood = 'happy';
```

## 📍 Массивы (`Array`)

| Название | Лимит | Описание |
|----------|-------|----------|
| `array[]` | до 1 ГБ суммарно | многомерные массивы любого типа |

**Пример создания и использования:**

```sql
CREATE TABLE pilots (
    pilot_name text,
    schedule integer[]
);

INSERT INTO pilots VALUES
    ('Ivan', '{1, 3, 5, 6, 7}'::integer[]),
    ('Petr', '{1, 2, 5, 7}'::integer[]),
    ('Pavel', '{2, 5}'::integer[]),
    ('Boris', '{3, 5, 6}'::integer[]);
```

> Массивы могут быть **многомерными**: `integer[][]`, `text[]`

## 📄 JSON типы

| Название | Описание |
|----------|----------|
| `json` | данные JSON (хранится как текст, сохраняет порядок ключей и повторяющиеся ключи) |
| `jsonb` | бинарное представление JSON (эффективнее для обработки) |

### ⚡ JSON vs JSONB

| Характеристика | `json` | `jsonb` |
|----------------|--------|---------|
| Скорость записи | ✅ быстрее | 🟡 медленнее (однократный разбор) |
| Скорость чтения | 🟡 медленнее (каждый раз разбор) | ✅ быстрее |
| Сохраняет порядок ключей | ✅ да | ❌ нет |
| Сохраняет повторяющиеся ключи | ✅ да | ❌ нет |

> **💡 Рекомендация:** `jsonb` предпочтительнее для большинства случаев.


## 💡 Ключевые особенности PostgreSQL

- **`text`** — основной тип для строк без ограничений длины
- **`varchar(n)`** — используют, когда нужны гарантии по длине
- **`jsonb`** — предпочтительнее `json` для большинства случаев
- **`serial`** — не настоящий тип, а удобное соглашение для автоинкремента
- **`array`** — могут быть многомерными: `integer[][]`, `text[]`
- **`enum`** — создаются через `CREATE TYPE`

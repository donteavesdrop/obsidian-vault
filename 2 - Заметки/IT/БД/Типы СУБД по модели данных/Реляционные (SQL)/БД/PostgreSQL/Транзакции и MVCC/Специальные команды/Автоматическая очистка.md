## Автоматическая очистка (Autovacuum)

**Автоматическая очистка** — механизм, позволяющий запускать обычную очистку в определенные моменты времени, в зависимости от количества изменений в таблицах.

### Особенности

- Работает аналогично обычной очистке
- Выполняется периодически для таблиц с определенным количеством изменений

### Процессы

| Процесс | Описание |
|---------|----------|
| **autovacuum launcher** | постоянно запущен, планирует запуск рабочих процессов |
| **autovacuum worker** | запускаются процессом postmaster по просьбе autovacuum launcher, подключаются к заданной БД, перебирают и очищают таблицы |

---

## Алгоритм работы

### Autovacuum launcher

- Для каждой базы данных (в которой есть активность) запускать рабочий процесс раз в `autovacuum_naptime`
- Количество рабочих процессов ≤ `autovacuum_max_workers`

---

### Autovacuum worker

Алгоритм: выполнять по очереди очистку всех таблиц, в которых число ненужных версий строк превышает:

```
autovacuum_vacuum_threshold + autovacuum_vacuum_scale_factor * число строк в таблице
```

А также выполнять анализ всех таблиц, в которых число изменившихся версий строк превышает:

```
autovacuum_analyze_threshold + autovacuum_analyze_scale_factor * число строк в таблице
```

> В одной БД может параллельно работать несколько процессов.

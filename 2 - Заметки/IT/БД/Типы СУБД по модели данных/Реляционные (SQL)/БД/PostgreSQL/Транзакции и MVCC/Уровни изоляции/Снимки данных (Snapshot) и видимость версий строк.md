## Снимки данных (Snapshot) и видимость версий строк

### Общие принципы

Физически в страницах данных могут находиться несколько версий одной и той же строки.

При этом каждая транзакция должна видеть только одну (или ни одной) версию каждой строки так, чтобы вместе они составляли согласованную в ACID-смысле картину данных на определенный момент времени.

Изоляция в PostgreSQL строится на основе снимков данных (snapshot): каждая транзакция работает со своим снимком данных, который «содержит» данные, которые были зафиксированы до момента создания снимка, и не «содержит» еще не зафиксированные на этот момент данные.

---

### Read Committed (схематичное представление)

```
Время
  │
  ▼
  ┌─────────────────────────────────────────────────────────┐
  │  Транзакция A                                           │
  │  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐  │
  │  │BEGIN  │  │SELECT │  │SELECT │  │SELECT │  │COMMIT │  │
  │  └───────┘  └───────┘  └───────┘  └───────┘  └───────┘  │
  │       ↑          ↑          ↑          ↑                 │
  │   Снимок 1   Снимок 2   Снимок 3   Снимок 4              │
  │   (начало   (запрос)   (запрос)   (запрос)               │
  │    запроса)                                              │
  └─────────────────────────────────────────────────────────┘
```

В режиме `Read Committed` снимок обновляется перед каждым оператором.

---

### Repeatable Read и Serializable (схематичное представление)

```
Время
  │
  ▼
  ┌─────────────────────────────────────────────────────────┐
  │  Транзакция A                                           │
  │  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐  │
  │  │BEGIN  │  │SELECT │  │SELECT │  │SELECT │  │COMMIT │  │
  │  └───────┘  └───────┘  └───────┘  └───────┘  └───────┘  │
  │       ↑                                      ↑           │
  │   Снимок                                    Снимок       │
  │   (начало                                  (начало      │
  │    транзакции)                             транзакции)  │
  └─────────────────────────────────────────────────────────┘
```

В режимах `Repeatable Read` и `Serializable` снимок создается один раз в начале транзакции (перед первым оператором).

### Видимость версий строк в снимке

Версия попадает в снимок, когда:
- изменения транзакции xmin видны для снимка
- изменения транзакции xmax не видны для снимка

Изменения транзакции видны, когда:
- изменения транзакции xmin видны для снимка
- изменения транзакции xmax не видны для снимка

Отдельные правила для видимости собственных изменений: учитывается порядковый номер операции в транзакции (cmin/cmax).

---

### Правила видимости

**Транзакции завершились до создания снимка – изменения видны**

```
Время создания снимка
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │                                 │
    │    ▼                                 │
    │  xmin=100 (COMMIT)                   │
    │  ✅ ВИДНА                             │
    └───────────────────────────────────────┘
```

**Транзакции начались после создания снимка – изменения не видны**

```
Время создания снимка
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │                                 │
    │    │         xmin=200 (ACTIVE)       │
    │    │         ❌ НЕ ВИДНА              │
    └───────────────────────────────────────┘
```

**Транзакции были активны в момент создания снимка – изменения не видны**

```
Время создания снимка
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │    xmin=150 (ACTIVE)            │
    │    │    ❌ НЕ ВИДНА                   │
    └───────────────────────────────────────┘
```

---

### Структура снимка данных

Снимок данных содержит:

| Компонент | Описание |
|-----------|----------|
| Номер самой ранней активной транзакции | xmin для снимка |
| Номер следующей транзакции | еще не существующей |
| Список активных транзакций | все транзакции, которые были активны в момент создания снимка |

---

### Пример с транзакциями

```sql
BEGIN;
INSERT INTO accounts VALUES (1, '1001', 'alice', 1000.00);
SELECT txid_current();
```

```
txid_current
3695
```

```sql
BEGIN;
INSERT INTO accounts VALUES (2, '2001', 'bob', 100.00);
SELECT txid_current();
```

```
txid_current
3696
```

```sql
COMMIT;
```

---

### Снимок в транзакции

```sql
BEGIN ISOLATION LEVEL REPEATABLE READ;
SELECT xmin, xmax, * FROM accounts;
```

| xmin | xmax | id | number | client | amount |
|------|------|----|--------|--------|--------|
| 3696 | 0 | 2 | 2001 | bob | 100.0 |

---

### Новая транзакция

```sql
BEGIN;
INSERT INTO accounts VALUES (3, '2002', 'bob', 900.00);
SELECT txid_current();
```

```
txid_current
3697
```

```sql
COMMIT;
```

---

### Снимок в транзакции (повторно)

```sql
SELECT xmin, xmax, * FROM accounts;
```

| xmin | xmax | id | number | client | amount |
|------|------|----|--------|--------|--------|
| 3696 | 0 | 2 | 2001 | bob | 100.0 |

Новая запись (3697) не видна, так как транзакция началась после создания снимка.

---

### Текущий снимок

```sql
SELECT txid_current_snapshot();
```

```
txid_current_snapshot
3695:3697:3695
```

### «Горизонт событий»

**Неактуальные версии строк не нужны снимку**

```
Снимок: xmin=100
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │                                 │
    │    │  xmax=90 (COMMIT)               │
    │    │  → версию можно удалить         │
    └───────────────────────────────────────┘
```

```sql
BEGIN;
SELECT backend_xmin FROM pg_stat_activity 
WHERE pid = pg_backend_pid();
```

```
backend_xmin
3699
```

---

### Горизонт событий (сравнение)

**Неактуальные версии строк можно удалять**

```
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │                                 │
    │    │  xmax=90 (COMMIT)               │
    │    │  ✅ МОЖНО УДАЛИТЬ                │
    └───────────────────────────────────────┘
```

**Неактуальные версии строк нельзя удалять**

```
         │
         ▼
    ┌────┼─────────────────────────────────┐
    │    │                                 │
    │    │  xmax=95 (ACTIVE)               │
    │    │  ❌ НЕЛЬЗЯ УДАЛИТЬ               │
    └───────────────────────────────────────┘
```

## Реляционная модель данных

**Реляционная модель данных** — это концептуальная модель, которая представляет данные в виде таблиц, состоящих из строк и столбцов. Каждая строка в таблице представляет собой отдельную запись, а каждый столбец — характеристику этой записи. Данные в таблице организованы в виде взаимосвязанных отношений, что позволяет эффективно хранить и обрабатывать информацию.

Реляционная модель позволяет создавать и управлять базами данных с помощью языка SQL (Structured Query Language). SQL предоставляет мощные средства для выполнения различных операций с данными, таких как выборка, фильтрация, сортировка, агрегирование и многое другое. Это делает реляционную модель очень гибкой и эффективной для решения широкого спектра задач, связанных с хранением и обработкой информации.

## Основные понятия реляционной модели

### Отношение

| | |
|---|---|
| **Определение** | Отношение — это таблица в реляционной базе данных, состоящая из строк (кортежей) и столбцов (атрибутов). |
| **Свойства** | Каждое отношение имеет уникальное имя и не содержит дубликатов строк. |
| **Пример** | Таблица «Сотрудники» с колонками «ID», «Имя», «Должность» — это отношение. |

---

### Атрибут и домен

**Атрибут**  
Атрибут — это столбец в таблице, представляющий определенное свойство сущности. Например, «Имя» в таблице «Сотрудники».

**Домен**  
Домен — это набор допустимых значений для атрибута. Например, домен для атрибута «Возраст» может быть целые числа от 0 до 120.

---

### Кортеж

| | |
|---|---|
| **Определение** | Кортеж — это строка в таблице, представляющая отдельный экземпляр сущности. |
| **Свойства** | Каждый кортеж уникален в рамках отношения и содержит значения для каждого атрибута. |
| **Пример** | В таблице «Сотрудники» строка «1, Иван Иванов, Менеджер» — это кортеж. |

---

### Кардинальность и степень

**Кардинальность**  
Кардинальность отношения — это количество корней (строк) в отношении. Она может меняться со временем.

**Степень**  
Степень отношения — это количество атрибутов (столбцов) в отношении. Обычно она остается постоянной.

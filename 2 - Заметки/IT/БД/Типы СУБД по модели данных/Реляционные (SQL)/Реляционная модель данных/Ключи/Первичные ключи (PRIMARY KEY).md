## Первичный ключ

### 1. Определение

Первичный ключ — это атрибут или набор атрибутов, уникально идентифицирующий каждый кортеж в отношении.

### 2. Свойства

Первичный ключ должен быть уникальным и не может содержать `NULL`-значения.

### 3. Пример

В таблице «Сотрудники» атрибут «ID сотрудника» может быть первичным ключом.

### 4. Значение

Первичные ключи обеспечивают уникальность записей и позволяют быстро находить нужные данные.

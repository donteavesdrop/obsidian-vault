## Аномалии в базах данных

### 1. Аномалия вставки

Невозможность добавить новые данные без наличия полной информации.

### 2. Аномалия удаления

Непреднамеренная потеря данных при удалении записи.

### 3. Аномалия обновления

Необходимость изменения множества записей для обновления одного факта.

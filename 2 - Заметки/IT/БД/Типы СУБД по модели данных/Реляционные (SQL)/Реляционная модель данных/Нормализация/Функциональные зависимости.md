## Функциональные зависимости

### Определение

Функциональная зависимость — это отношение между атрибутами, где значение одного атрибута однозначно определяет значение другого.

### Обозначение

**X → Y**, где X функционально определяет Y.

### Пример

В таблице «Сотрудники» ID сотрудника → Имя сотрудника.

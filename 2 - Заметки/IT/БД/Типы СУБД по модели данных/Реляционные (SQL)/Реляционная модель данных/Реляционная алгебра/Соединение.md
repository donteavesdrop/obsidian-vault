## Реляционная алгебра: Соединение (Join)

### 1. Определение

Соединение — это операция, которая комбинирует кортежи из двух отношений на основе связанных атрибутов.

### 2. Типы

Естественное соединение, тета-соединение, внешнее соединение.

### 3. Обозначение

**⋈** (знак соединения) с условием в нижнем индексе для тета-соединения.

### 4. Пример

Сотрудники ⋈ Отделы соединит таблицы по соответствующим атрибутам.

# Метод Казински

Метод Казински (Kasiski examination) — криптоаналитический метод, используемый для определения длины ключа в шифрах, основанных на повторяющемся ключе (например, шифр Виженера). Предложен Фридрихом Казински в 1863 году.

## Основная идея

Если в зашифрованном тексте встречаются одинаковые последовательности символов (повторы), то расстояние между ними с большой вероятностью кратно длине ключа. Анализируя все повторяющиеся фрагменты и находя наибольший общий делитель расстояний между ними, можно оценить длину ключа.

## Алгоритм (упрощённая версия)

1. Удалить из шифротекста все небуквенные символы (пробелы, знаки препинания, цифры).
    
2. Привести все буквы к одному регистру (обычно нижнему).
    
3. Для каждого возможного смещения `shift` от 1 до длины текста подсчитать количество позиций `i`, где `text[i] == text[i+shift]`.
    
4. Найти смещения с максимальным количеством совпадений — они являются кандидатами на длину ключа (или её множителями).
    
5. Часто в качестве длины ключа берут наименьшее из таких смещений (или НОД нескольких самых частых).
    

## Пример реализации на Python

python

import re
from collections import Counter
def preprocess_text(text):
    # Удаляем всё, кроме букв, и приводим к нижнему регистру
    return re.sub(r'[^а-яА-Я]', '', text).lower()
def kasiski_method(text):
    processed = preprocess_text(text)
    n = len(processed)
    coincidences = {}
    for shift in range(1, n):
        count = sum(1 for i in range(n - shift) if processed[i] == processed[i + shift])
        coincidences[shift] = count
    # 5 наиболее частых смещений
    likely_lengths = [k for k, v in Counter(coincidences).most_common(5)]
    return coincidences, likely_lengths
# Пример использования с шифротекстом из практической работы
ciphertext = """
у гуфрцьс щуднутбаоэ щчгчо д ёцюйту г гуфрцьбюм илав ъъовтчыэщкш...
"""
coincidences, likely_lengths = kasiski_method(ciphertext)
print("Вероятные длины ключа:", likely_lengths)
print("Наиболее вероятная длина:", min(likely_lengths) if likely_lengths else "не найдена")

## Результат 

- После обработки зашифрованного сообщения были получены смещения с максимальным количеством совпадений.
    
- Наиболее вероятная длина ключа составила **5**.
    
- Данный результат позволяет далее применить частотный анализ для блоков, разделённых на группы по 5 символов, и полностью раскрыть ключ.

# Шифр Виженера

**Тип:** Симметричный, многоалфавитный шифр подстановки  
**Ключ:** Слово или фраза, задающая циклический сдвиг букв

## Принцип работы

Шифр Виженера использует последовательность сдвигов, определяемых ключевым словом. Каждая буква открытого текста сдвигается на величину, соответствующую букве ключа (A=0, B=1, …, Z=25). Ключ повторяется циклически.

**Шифрование:**  
`C_i = (P_i + K_{i mod |K|}) mod 26`

**Расшифрование:**  
`P_i = (C_i - K_{i mod |K|}) mod 26`

## Пример из практической работы

**Зашифрованный текст:**  
`QUQGY{v1q3g3v3_r1vz_o3_a4pzr}`  
**Известное начало открытого текста:** `VKCTF` (формат флага)

### Генерация ключа по известному фрагменту

Если известна часть открытого текста, можно восстановить соответствующий отрезок ключа:

```python
def vigenere_generate_key(ciphertext, plaintext):
    key = []
    for ciph_char, plain_char in zip(ciphertext, plaintext):
        if ciph_char.isalpha():
            shift = (ord(ciph_char) - ord(plain_char)) % 26
            key.append(chr(shift + ord('A')))
        else:
            key.append(ciph_char)
    return ''.join(key)
```
Для фрагмента `"QUQGY"` (шифр) и `"VKCTF"` (открытый текст) получаем ключ `"VKONT"`.

```python
def vigenere_decrypt(ciphertext, key):
    decrypted = []
    key_index = 0
    for char in ciphertext:
        if 'a' <= char <= 'z':
            shift = ord(key[key_index % len(key)]) - ord('A')
            decrypted.append(chr((ord(char) - ord('a') - shift) % 26 + ord('a')))
            key_index += 1
        elif 'A' <= char <= 'Z':
            shift = ord(key[key_index % len(key)]) - ord('A')
            decrypted.append(chr((ord(char) - ord('A') - shift) % 26 + ord('A')))
            key_index += 1
        else:
            decrypted.append(char)
    return ''.join(decrypted)```

Применяя ключ `"VKONT"` (дополненный до нужной длины, например `"VKONTAKTE"`), получаем:

**Результат:** `VKCTF{v1g3n3r3_w1ll_b3_h4ppy}`

## Особенности и криптостойкость

- Классический шифр Виженера уязвим для **атаки Казински** (определение длины ключа) и **частотного анализа** внутри блоков.
    
- Без знания ключа взлом возможен, если длина ключа небольшая (до 10–15 символов).
    
- При длине ключа, сравнимой с длиной сообщения, и случайном ключе приближается к **одноразовому блокноту**, но не является им (ключ повторяется).

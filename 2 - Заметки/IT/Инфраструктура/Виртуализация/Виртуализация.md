▪ Набор вычислительных ресурсов, обеспечивающее логическую изоляцию вычислительных процессов, выполняемых на одном физическом ресурсе (хост).

▪ Для каждого приложения разворачивается полноценная ОС.

▪ Гипервизор требуется для одновременной работы нескольких виртуальных машин на одном хосте.

![[Pasted image 20260423105936.png]]

#### Особенности виртуализации

▪ Зачастую представлено одним сервером или несколькими ВМ

▪ Полная изоляция окружений

▪ Выделение ресурсов по запросу

▪ ВМ требует виртуализации железа под гостевую ОС

#### Проблемы виртуализации

 Гипервизоры большие, медленные и зачастую платные.

 ВМ чересчур избыточно по ресурсам для небольших приложений и микросервисов.

 Много сложностей для обмена данными между приложениями из разных ВМ.

 Плохая переносимость приложений между системами.

Назрела необходимость в совершенно ином подходе к построению архитектуры приложений, при котором ядро операционной системы поддерживает несколько изолированных экземпляров пользовательского пространства* (namespaces) вместо одного.

Так возникла новая технология виртуализации – контейнеризация, которая использует ядро хостовой системы, оставаясь при не менее функциональной и обеспечивающей необходимую изоляцию

# Swagger Codegen

**Swagger Codegen** — это консольный инструмент для генерации серверного и клиентского кода на основе спецификации.

### Возможности

- Генерирует код на JavaScript, Java, Python, Go, TypeScript, Swift, C# и других языках программирования
- Отвечает за генерацию интерактивной документации, доступной из браузера

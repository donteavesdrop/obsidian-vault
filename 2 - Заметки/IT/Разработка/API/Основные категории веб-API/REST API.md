# REST API

**REST API** — это API, следующий принципам архитектуры **REST** (Representational State Transfer), в которой взаимодействие с ресурсами другой программы осуществляется через HTTP-запросы (`GET`, `POST`, `PUT`, `DELETE`), представленные в виде URL-адресов (эндпоинтов или end points).

Например, получение, отправка, удаление и изменение контента на сайтах в Интернете выполняются через отправку соответствующих запросов по конкретным URL с указанием дополнительных параметров, если таковые требуются:

### Примеры HTTP-запросов

**Получение главной страницы**

```http
GET / HTTP/1.1
Host: site.ru
```

**Получение первой страницы со списком статей**

```http

GET /site.ru/page/1 HTTP/1.1
Host: site.ru
```

**Получение второй страницы со списком статей**

```http

GET /site.ru/page/2 HTTP/1.1
Host: site.ru
```

**Публикация новой статьи**

```http

POST /site.ru/newarticle HTTP/1.1
Host: site.ru
```

**Удаление существующей статьи**

```http

DELETE /site.ru/article/nekaya-lishnya-statya HTTP/1.1
Host: site.ru
```

Таким образом, **REST API** является расширением API, которое указывает на конкретный тип взаимодействия между программами.

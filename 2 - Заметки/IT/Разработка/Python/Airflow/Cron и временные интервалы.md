## 🎯 Быстрые пресеты (Presets)

| Пресет | Значение | Cron выражение |
|---|---|---|
| `None` | Без расписания, только ручной запуск | - |
| `@once` | Запустить один раз | - |
| `@continuous` | Запускается сразу после завершения предыдущего | - |
| `@hourly` | Каждый час в 00 минут | `0 * * * *` |
| `@daily` | Каждый день в 00:00 | `0 0 * * *` |
| `@weekly` | Каждое воскресенье в 00:00 | `0 0 * * 0` |
| `@monthly` | Первое число каждого месяца в 00:00 | `0 0 1 * *` |
| `@quarterly` | Первое число каждого квартала в 00:00 | `0 0 1 */3 *` |
| `@yearly` | 1 января каждого года в 00:00 | `0 0 1 1 *` |

## ⏰ Cron выражения - синтаксис

```
┌───────────── минуты (0-59)
│ ┌───────────── часы (0-23)  
│ │ ┌───────────── день месяца (1-31)
│ │ │ ┌───────────── месяц (1-12)
│ │ │ │ ┌───────────── день недели (0-6, 0=воскресенье)
│ │ │ │ │
* * * * *
```

## 📝 Популярные примеры

### Ежедневные запуски
```python
'0 9 * * *'      # Каждый день в 09:00
'0 18 * * 1-5'   # В будни в 18:00
'0 6,18 * * *'   # В 06:00 и 18:00 ежедневно
```

### Еженедельные запуски
```python
'0 12 * * 1'     # Каждый понедельник в 12:00
'0 0 * * 0'      # Каждое воскресенье в полночь
'0 9 * * 2,4'    # По вторникам и четвергам в 09:00
```

### Ежемесячные запуски
```python
'0 0 1 * *'      # Первое число месяца
'0 8 15 * *'     # 15-го числа каждого месяца в 08:00
'0 0 1,15 * *'   # 1-го и 15-го числа каждого месяца
```

## 🔄 Комбинированные примеры для бизнес-задач

```python
# ETL процессы
'0 2 * * *'      # Ежедневная выгрузка в 02:00 ночи
'0 */6 * * *'    # Каждые 6 часов
'0 9-18 * * 1-5' # Каждый час с 09:00 до 18:00 в рабочие дни

# Отчетность
'0 8 * * 1'      # Понедельник в 08:00 - недельные отчеты
'0 6 1 * *'      # Первое число месяца в 06:00 - месячные отчеты
```

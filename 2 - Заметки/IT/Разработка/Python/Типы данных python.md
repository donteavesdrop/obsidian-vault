## 🔢 Числовые типы

```python
int - неограниченной точности: целые числа любой величины
float - ±1.8e308, точность ~15 знаков: числа с плавающей точкой
complex - аналогично float: комплексные числа (re + im)
bool - True/False: логические значения
```

## 📝 Строковые типы

```python
str - неограниченная длина: строки Unicode
bytes - неограниченная длина: неизменяемые байтовые строки
bytearray - неограниченная длина: изменяемые байтовые строки
```

## 🧺 Последовательности

```python
list - до 2³² элементов: изменяемые массивы произвольных типов
tuple - до 2³² элементов: неизменяемые массивы произвольных типов
range - до 2³² элементов: последовательности чисел (start, stop, step)
```

## 🗂️ Множества

```python
set - до 2³² элементов, уникальные: неупорядоченные коллекции
frozenset - до 2³² элементов, уникальные: неизменяемые множества
```

## 🗄️ Словари

```python
dict - до 2³² пар ключ-значение: хеш-таблицы
```

## 💾 Специальные типы

```python
NoneType - одно значение None: отсутствие значения
bytes - до 2³² байт: бинарные данные
memoryview - зависит от объекта: "вид" на память других объектов
```

## 🎯 Ключевые ограничения:

- **2³² элементов** = ~4.3 миллиарда элементов
- **Практически все типы** ограничены только объемом оперативной памяти
- **Исключение** - `float` имеет фиксированный диапазон и точность

## 📌 Особенности:

```python
# int - абсолютно безграничен (если хватает RAM)
very_big_int = 10**1000  # работает!

# str - может быть огромной
huge_string = "x" * 10_000_000  # 10 млн символов

# list/dict - ограничены только памятью
big_list = [0] * 1_000_000  # 1 млн элементов
```

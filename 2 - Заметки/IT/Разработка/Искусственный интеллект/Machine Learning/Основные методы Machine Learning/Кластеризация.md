# Кластеризация

**Кластеризация** — это метод, который группирует похожие объекты, когда у нас нет заранее известных категорий. Например, он может разделить клиентов магазина на группы по их интересам.

Популярные способы кластеризации:

- **K-Means**
- **DBSCAN**
- **Иерархическая кластеризация**

---

## Пример использования

Допустим, у вас есть интернет-магазин одежды, и вы хотите лучше понять своих покупателей. Используя алгоритм **K-Means**, вы анализируете данные о покупках, такие как:

- тип одежды (спортивная, повседневная, деловая)
- частота заказов

Модель делит клиентов на группы:

- одна группа предпочитает спортивную одежду и часто покупает кроссовки
- другая выбирает вечерние платья для редких мероприятий

Это помогает настроить персонализированные рассылки с акциями для каждой группы.

# Лингвистические переменные

## Определение

**Лингвистическая переменная** — это переменная, значениями которой являются не числа, а слова или фразы естественного языка (термы). Формально лингвистическая переменная задается как:

< β, T, X >


где:

- **β** — имя лингвистической переменной
- **T** — терм-множество (набор лингвистических значений)
- **X** — универсум (диапазон числовых значений)

## Пример лингвистических переменных из задачи подбора объема блюд

### 1. Калорийность

| Компонент | Значение |
|-----------|----------|
| Имя переменной (β) | «калорийность» |
| Терм-множество (T) | «большая», «средняя», «низкая» |
| Универсум (X) | [2, 5] (×100 ккал) |

### 2. Острота

| Компонент | Значение |
|-----------|----------|
| Имя переменной (β) | «острота» |
| Терм-множество (T) | «маленькая», «средняя», «большая» |
| Универсум (X) | [1, 20] (степень остроты) |

### 3. Объем блюд

| Компонент | Значение |
|-----------|----------|
| Имя переменной (β) | «объем блюд» |
| Терм-множество (T) | «мало», «достаточно», «много» |
| Универсум (X) | [1, 7] (литры) |

### 4. Количество едоков

| Компонент | Значение |
|-----------|----------|
| Имя переменной (β) | «количество едоков» |
| Терм-множество (T) | «большое», «среднее», «маленькое» |
| Универсум (X) | [1, 20] (человек) |

## Роль лингвистических переменных

Лингвистические переменные позволяют:
- Формулировать правила на естественном языке
- Скрывать сложность числовых вычислений от пользователя
- Настраивать систему под предметную область

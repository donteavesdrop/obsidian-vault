# Нечеткая логика

## Определение

**Нечеткая логика** (Fuzzy Logic) — раздел математики, обобщающий классическую логику для работы с неопределенными и приблизительными понятиями. В отличие от бинарной логики (0 или 1), нечеткая логика оперирует степенями истинности в интервале [0, 1].

## Области применения

- Системы управления (стиральные машины, кондиционеры, поезда метро)
- Экспертные системы
- Системы поддержки принятия решений
- Распознавание образов
- Прогнозирование

## Ключевые понятия

| Понятие | Описание |
|---------|----------|
| **Лингвистическая переменная** | переменная, значениями которой являются слова или фразы естественного языка |
| **Терм-множество** | набор лингвистических значений переменной |
| **Функция принадлежности** | функция, отображающая значение переменной в степень принадлежности к нечеткому множеству |
| **Нечеткое правило** | правило вида «ЕСЛИ ... ТО ...», использующее лингвистические переменные |
| **Нечеткий вывод** | процедура получения заключения на основе нечетких правил и входных данных |

## Преимущества

- Способность работать с неточными и неполными данными
- Приближение к естественному языку человека
- Возможность формализации экспертных знаний

## Недостатки

- Субъективность при построении функций принадлежности
- Отсутствие единой методологии настройки
- Вычислительная сложность при большом количестве правил

# Подбор объема блюд (ручной расчет)

## Постановка задачи

Построить нечеткую базу знаний для задачи подбора объема блюд, учитывая:
- калорийность
- остроту
- количество едоков

## 1. Формулировка правил на естественном языке

1. Если калорийность **большая**, острота **маленькая**, количество едоков **маленькое**, то объем блюд = **мало**
2. Если калорийность **большая**, острота **большая**, количество едоков **среднее**, то объем блюд = **достаточно**
3. Если калорийность **средняя**, острота **большая**, количество едоков **большое**, то объем блюд = **много**
4. Если калорийность **низкая**, острота **средняя**, количество едоков **маленькое**, то объем блюд = **достаточно**

## 7. Агрегация посылок правил

| Правило | Расчет | Результат |
|---------|--------|-----------|
| Правило 1 | min(0, 0.125, 0.5) | 0 |
| Правило 2 | min(1, 0.5, 0.125) | 0.125? → **0.5** (по данным расчета в тексте) |
| Правило 3 | min(1, 0.125, 0.5) | 0.125 |
| Правило 4 | min(0, 0, 0) | 0 |

> **Примечание:** В исходном решении для правила 2 указано значение 0.5. Уточнение: при использовании операции max для объединения термов одной переменной (например, для остроты «достаточно» и «много») получается значение 0.5.

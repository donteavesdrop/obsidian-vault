# Функции принадлежности

## Определение

**Функция принадлежности** (membership function) — это функция μ(x), которая отображает значение x из универсума X в степень принадлежности к нечеткому множеству. Степень принадлежности принимает значения в интервале [0, 1].

## Основные типы функций принадлежности

| Тип | Описание | Формула (условно) |
|-----|----------|-------------------|
| **Треугольная** | Линейный рост и спад | μ(x) = max(0, min((x-a)/(b-a), (c-x)/(c-b))) |
| **Трапециевидная** | Плоская вершина | μ(x) = max(0, min((x-a)/(b-a), 1, (d-x)/(d-c))) |
| **Гауссова** | Колоколообразная кривая | μ(x) = e^(-(x-c)²/(2σ²)) |
| **Сигмоидальная** | S-образная кривая | μ(x) = 1/(1+e^(-a(x-c))) |

## Функции принадлежности из задачи подбора объема блюд

### Линейная переменная «Калорийность» (Рис. 3.1)

- **«низкая»** — трапециевидная форма на диапазоне [1, 4]
- **«средняя»** — трапециевидная форма на диапазоне [2, 5]
- **«большая»** — трапециевидная форма на диапазоне [4, 7]

### Лингвистическая переменная «Острота» (Рис. 3.2)

- **«маленькая»** — трапециевидная форма на диапазоне [1, 6]
- **«средняя»** — трапециевидная форма на диапазоне [2, 11]
- **«большая»** — трапециевидная форма на диапазоне [8, 20]

### Лингвистическая переменная «Объем блюд» (Рис. 3.3)

- **«мало»** — треугольная или трапециевидная форма
- **«достаточно»** — треугольная форма
- **«много»** — треугольная форма

### Лингвистическая переменная «Количество едоков» (Рис. 3.4)

- **«маленькое»** — трапециевидная форма на диапазоне [1, 6]
- **«среднее»** — трапециевидная форма на диапазоне [2, 11]
- **«большое»** — трапециевидная форма на диапазоне [8, 20]

## Выбор формы функции принадлежности

- **Треугольная форма** — проста в вычислениях, подходит для быстрых систем
- **Трапециевидная форма** — позволяет моделировать интервалы полной уверенности
- **Гауссова форма** — плавные переходы, но сложнее в вычислениях

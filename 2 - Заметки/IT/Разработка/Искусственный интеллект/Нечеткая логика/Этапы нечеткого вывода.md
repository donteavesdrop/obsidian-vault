# Этапы нечеткого вывода

## Общая схема

Входные данные (четкие)  
↓  
ФАЗЗИФИКАЦИЯ  
(преобразование в нечеткие множества)  
↓  
АГРЕГАЦИЯ ПОСЫЛОК  
(вычисление степеней уверенности правил)  
↓  
АККУМУЛЯЦИЯ  
(объединение активированных заключений)  
↓  
ДЕФАЗЗИФИКАЦИЯ  
(преобразование в четкое значение)  
↓  
Выходные данные (четкие)


## 1. Фаззификация

Преобразование четких входных значений в степени принадлежности к нечетким множествам с помощью функций принадлежности.

**Пример из задачи:**
- Калорийность = 4 → степень принадлежности к «средняя» = 1
- Острота = 9 → степень принадлежности к «средняя» = 0.5, к «большая» = 0.125
- Количество едоков = 10 → степень принадлежности к «средняя» = 0.125, к «большая» = 0.5

## 2. Агрегация посылок правил

Для каждого правила вычисляется степень уверенности посылки. Обычно используется операция **min** (логическое И) для конъюнкции условий.

**Пример из задачи:**
- Правило 1: min(0, 0.125, 0.5) = 0
- Правило 2: min(1, 0.5, 0.5) = 0.5
- Правило 3: min(1, 0.125, 0.5) = 0.125
- Правило 4: min(0, 0, 0) = 0

## 3. Аккумуляция

Объединение активированных заключений всех правил. Обычно используется операция **max** (логическое ИЛИ). Результатом является нечеткое множество, описывающее выходную переменную.

## 4. Дефаззификация

Преобразование нечеткого выходного множества в четкое число. Наиболее распространенные методы:

| Метод | Описание |
|-------|----------|
| **Центр тяжести** (Centroid) | Геометрический центр фигуры под кривой |
| **Средний максимум** (Mean of Maxima) | Среднее значение точек с максимальной принадлежностью |
| **Наименьший максимум** (Smallest of Maxima) | Наименьшее значение с максимальной принадлежностью |
| **Наибольший максимум** (Largest of Maxima) | Наибольшее значение с максимальной принадлежностью |

**Результат из задачи:** объем блюд ≥ 2.75 литров (степень уверенности 0.5)

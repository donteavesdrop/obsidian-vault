_2.6.2. Алгоритм, инспирированный летучими мышами (Bat-Inspired, BI),_ предложил Янг (X.-Sh. Yang) в 2010 г. [30].

Большинство видов летучих мышей обладает удивительно совершенными средствами эхолокации, которая используется ими для обнаружения добычи и препятствий, а также для обеспечения возможности разместиться в темноте на насесте. Параметры лоцирующего звукового импульса мышей различных видов меняются в широких пределах, отражая их различные охотничьи стратегии. Большинство мышей используют короткие частотно-модулированные в пределах примерно одной октавы сигналы. В то же время некоторые виды не используют частотную мо- дуляцию своих звуковых импульсов.

Алгоритм Ві предполагает следующую модель поведения летучих мышей:

a) с помощью эхолокации все мыши могут измерять расстояние до добычи и препятствий, а также различать их;

б) мыши движутся случайным образом. Текущие положение и скорость мыши равны X, V соответственно. Для поиска добычи мыши генерируют сигналы, имеющие частоту о и громкость а. В процессе поиска мыши могут менять частоту этих сигналов, а также частоту повторения излучаемых импульсов

b) частота сигналов может изменяться в диапазоне

@max > @min > 0, а громкость сигналов в пределах [0; 1].

**Описание алгоритма и структуры программы**

Основные этапы :

**Инициализация популяции**:

·         Генерируем случайную популяцию агентов (летучих мышей), где каждый агент имеет параметры положения, скорости, частоты и громкости сигнала.

·         Также выбирается глобально лучший агент xbest

**Перемещение агентов**:

·         Каждый агент перемещается в поисках решения с использованием двух частей: одной, связанной с направлением к лучшему решению (глобальному или локальному), и другой случайной части, отвечающей за случайные отклонения.

**Процесс локального поиска**:

·         После перемещения агента выполняется локальный поиск вокруг его текущего положения:

1.     Генерируется случайное новое положение с варьированием текущего положения.

2.     Вычисляется фитнес-функция (качество решения).

3.     Если новое положение улучшает решение, оно принимается, иначе повторяется.

**Обновление параметров**:

·         Параметры частоты и громкости обновляются с учетом эволюции:

o    Громкость α уменьшается линейно с количеством итераций, чтобы агенты искали всё менее значительные улучшения.

o    Частота повторения импульсов r уменьшается экспоненциально с итерациями.

**Обновление лучшего решения**:

·         В каждом шаге выбирается новое глобальное лучшее решение, если найдено улучшение.

**Окончание работы**:

·         Алгоритм завершает свою работу, если достигнуто максимальное количество итераций или если улучшения в решении становятся минимальными.

def bat_algorithm(pop_size, dim, bounds, max_iter):  
    positions, velocities, frequencies, loudness = initialize_agents(pop_size, dim, bounds)  
    fitness_values = np.apply_along_axis(fitness, 1, positions)  
    best_solution = positions[np.argmin(fitness_values)]  
    best_fitness = np.min(fitness_values)

    for iteration in range(max_iter):
        for i in range(pop_size):  
            rand = np.random.rand()
            if rand > 0.5:  
                positions[i] += velocities[i]

             Локальный поиск
            if np.random.rand() > 0.5:  
                new_pos = positions[i] + np.random.uniform(-1, 1, dim)  
                new_fitness = fitness(new_pos)
                if new_fitness < fitness_values[i]:  
                    positions[i] = new_pos  
                    fitness_values[i] = new_fitness

             Обновление громкости и частоты
            loudness[i] = loudness[i]  0.9
            frequencies[i] = frequencies[i]  (1 - np.exp(-0.1))

             Обновление лучшего решения
            if fitness_values[i] < best_fitness:  
                best_solution = positions[i]  
                best_fitness = fitness_values[i]

        print(f"Итерация {iteration + 1}, Лучшее решение: {best_solution}, Лучший фитнес: {best_fitness}")

    return best_solution, best_fitness

- Эта функция инициализирует агентов (летучих мышей). Каждый агент имеет:

  - positions (позиции) — случайные значения в заданных границах (bounds), представляющие решение задачи.

  - velocities (скорости) — случайные значения в диапазоне от -1 до 1.

  - frequencies (частоты) — случайные значения от 0 до 1, которые могут быть использованы для моделирования поведения мышей.

  - loudness (громкость) — также случайные значения от 0 до 1, регулирующие то, насколько сильно агент "голосит", что может влиять на поиск.

 3. Основной цикл алгоритма

def bat_algorithm(pop_size, dim, bounds, max_iter):

    positions, velocities, frequencies, loudness = initialize_agents(pop_size, dim, bounds)

    fitness_values = np.apply_along_axis(fitness, 1, positions)

    best_solution = positions[np.argmin(fitness_values)]

    best_fitness = np.min(fitness_values)

    for iteration in range(max_iter):

        for i in range(pop_size):

            rand = np.random.rand()

            if rand > 0.5:

                positions[i] += velocities[i]

             Локальный поиск

            if np.random.rand() > 0.5:

                new_pos = positions[i] + np.random.uniform(-1, 1, dim)

                new_fitness = fitness(new_pos)

                if new_fitness < fitness_values[i]:

                    positions[i] = new_pos

                    fitness_values[i] = new_fitness

             Обновление громкости и частоты

            loudness[i] = loudness[i]  0.9

            frequencies[i] = frequencies[i]  (1 - np.exp(-0.1))

             Обновление лучшего решения

            if fitness_values[i] < best_fitness:

                best_solution = positions[i]

                best_fitness = fitness_values[i]

        print(f"Итерация {iteration+1}, Лучшее решение: {best_solution}, Лучший фитнес: {best_fitness}")

    return best_solution, best_fitness

- Основной цикл состоит из двух вложенных циклов:

  - Внешний цикл (по итерациям) повторяется до достижения максимального числа итераций max_iter.

  - Внутренний цикл (по агентам) выполняется для каждого агента (летучей мыши) в популяции.

  Каждая итерация алгоритма состоит из нескольких этапов:

  - Обновление позиции с использованием скорости:

    rand = np.random.rand()

    if rand > 0.5:

        positions[i] += velocities[i]

    На каждом шаге с вероятностью 0.5 агент может двигаться на основе своей текущей скорости. Это моделирует случайное поведение мыши.

  - Локальный поиск:

    if np.random.rand() > 0.5:

        new_pos = positions[i] + np.random.uniform(-1, 1, dim)

        new_fitness = fitness(new_pos)

        if new_fitness < fitness_values[i]:

            positions[i] = new_pos

            fitness_values[i] = new_fitness

    Иногда агент выполняет локальный поиск, случайно изменяя свою позицию и проверяя, улучшилось ли решение (если новое решение имеет меньший фитнес, то оно принимается).

  - Обновление громкости и частоты:

    - Громкость уменьшается с каждым шагом (умножается на 0.9).

    - Частота изменяется с помощью экспоненциальной функции.

    loudness[i] = loudness[i]  0.9

    frequencies[i] = frequencies[i]  (1 - np.exp(-0.1))

  - Обновление лучшего решения:

    Если текущий фитнес агента лучше, чем лучший найденный фитнес, то обновляется лучшее решение:

    if fitness_values[i] < best_fitness:

        best_solution = positions[i]

        best_fitness = fitness_values[i]

- В конце каждой итерации выводятся текущие результаты (лучшее решение и фитнес).

# Компьютерная безопасность (семантическая сеть)

## Исходные вершины графа

| Вершина | Описание |
|---------|----------|
| Компьютерная безопасность | целевое понятие предметной области |
| Пользователи | субъекты, осуществляющие обеспечение безопасности |
| Источники угроз (нарушители) | субъекты, наносящие ущерб безопасности |
| Физические средства защиты | средства обеспечения безопасности |
| Базовые средства защиты | средства обеспечения безопасности |
| Анти-DDoS | средство защиты от DDoS-атак |
| Резервное копирование | средство защиты данных |
| План аварийного восстановления данных | средство восстановления после сбоев |
| Шифрование | средство защиты информации |
| Уязвимости | слабые места системы |

## Отношения между вершинами

Типы отношений определяются согласно стандартной классификации семантических сетей (например, функциональные связи, отношения наследования, причинно-следственные связи).

## Конкретный факт задачи

Антон заметил подозрительное поведение устройства после перехода по подозрительной ссылке, которую ему отправил Кирилл. Антон запустил план аварийного восстановления данных, чтобы устранить уязвимости, ведущие к рискам потери данных (ухудшения компьютерной безопасности).

## Проверка установленных связей

Возьмём вершину **«ссылка»** и пройдём по установленным связям:

Ссылка → является вредоносным ПО → содержит угрозы → используют уязвимости системы → ведут к нарушению целостности файлов → является риском для компьютерной безопасности

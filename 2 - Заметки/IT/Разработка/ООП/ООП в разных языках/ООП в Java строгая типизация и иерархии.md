----
В Java **объектно-ориентированное программирование** — основа языка: классы, интерфейсы, абстрактные классы, модификаторы доступа. Наследование, полиморфизм и переопределение методов встречаются в каждом проекте. **Курс ООП Java** — [ООП в Java](https://ru.hexlet.io/programs/java-oop) — разбирает полиморфизм, наследование, аннотации и интерфейсы. После него естественно углубиться в [Дженерики в Java](https://ru.hexlet.io/programs/java-generics) и [Стримы в Java](https://ru.hexlet.io/programs/java-streams) — обобщения и работа с коллекциями тесно связаны с типами и ООП. Базу мышления даёт [СИКП на Java](https://ru.hexlet.io/programs/java-sicp); альтернативный взгляд — [Функциональное программирование на Java](https://ru.hexlet.io/programs/java-functional-programming). Для веб-приложений на Java пригодится [Spring Boot](https://ru.hexlet.io/programs/spring-boot).

## Получить список гипертаблиц
``` sql
SELECT hypertable_schema, hypertable_name

FROM timescaledb_information.hypertables;
```

---
## Проверка политик сжатия и удаления
``` sql
SELECT
hypertable_schema,
hypertable_name,
proc_name,
schedule_interval,
config
FROM timescaledb_information.jobs
WHERE hypertable_name IN ('1c_fillers_history_stocks', 'ozon_fillers_history_stocks')
AND proc_name IN ('policy_compression', 'policy_retention');
```
Выводит данные в формате

| hypertable_name             | proc_name        | hypertable_schema | schedule_interval | config                                       |
| --------------------------- | ---------------- | ----------------- | ----------------- | -------------------------------------------- |
| ozon_fillers_history_stocks | policy_retention | public            | 1 day             | {"drop_after": "1 year", "hypertable_id": 7} |

## Удаление политик
#### Удаление политики сжатия
``` sql
SELECT remove_compression_policy('ozon_fillers_history_stocks');
```
#### Удаление политики удаления
``` sql
SELECT remove_retention_policy('ozon_fillers_history_stocks');
```

---

### Добавление политик

#### Добавление политики сжатия
``` sql
SELECT add_compression_policy('ozon_fillers_history_stocks', INTERVAL '6 months');
``` 
#### Добавление политики удаления
``` sql
SELECT add_retention_policy('ozon_fillers_history_stocks', INTERVAL '2 years');
```

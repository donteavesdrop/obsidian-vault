# Моё хранилище Obsidian

## Структура

- **1 - Черновики**  
  Всё, что ещё не готово: быстрые записи, идеи, временные файлы.

- **2 - Заметки**  
  Основная база знаний. Внутри — тематические разделы (IT, языки, инструменты, общие вопросы и т.д.). Иерархия может расширяться.

- **3 - Теги**  
  Автоматические или ручные страницы с тегами для навигации.

- **4 - Индексы**  
  Карты содержания (MOC) по ключевым темам. Служат точками входа в крупные разделы.

- **5 - Исходные материалы**  
  Внешние источники: статьи, документация, выдержки из книг, ссылки.

- **6 - Шаблоны**  
  Заготовки для новых заметок (например, для определённых типов записей).

- **7 - Подтемы для индексов**  
  Вспомогательные файлы, которые расширяют индексы или используются для автоматизации.

## Принцип работы

- Новые заметки создаются в соответствующих подпапках внутри `2 - Заметки`.
- Для быстрого доступа — глобальный поиск или индексы из папки `4 - Индексы`.
- Шаблоны ускоряют создание однотипных заметок.
